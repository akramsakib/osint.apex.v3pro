## 🛠️ The 24 Active Built-In Offline Engines

The workbench includes **24 active, interactive, client-side tools** organized into 7 investigative categories:

### 🪪 1. Global National ID & Forensic Identity Decoders
1. 🇲🇾 **Malaysian MyKad Engine**: Full 12-digit IC parser (DOB, Age, Gender, JPN State/Country origin Codes 01–99) + automated SSM e-Info, SPR voter, PDRM, and `.edu.my` query generators.
2. 🇺🇸 **US Social Security Number (SSN) Decoder**: Pre-2011 3-digit SSA Area number state identification, group issuance timeline, and geographic allocation validator.
3. 🇬🇧 **UK National Insurance Number (NINO) Validator**: HMRC syntax rules and administrative suffix verification.
4. 🇮🇳 **Indian Aadhaar (UIDAI) & PAN Card Validator**: 12-digit Aadhaar Verhoeff checksum algorithm + 10-char PAN tax structure & entity classifier.
5. 🇨🇳 **Chinese Resident Identity Card (GB 11643-1999)**: 18-digit ISO 7064 Mod 11-2 checksum validator, DOB, gender, and administrative province decoder.
6. 🇪🇸 **Spanish DNI / NIE / CIF Validator**: Modulo 23 control letter calculation and official tax ID format checker.

### 💳 2. Global Banking & Financial Intelligence (FININT)
7. 💳 **Payment Card Luhn Checksum (Mod 10) & BIN/IIN Classifier**: Real-time ISO/IEC 7812 Luhn validator, Major Industry Identifier (MII), and Card Network brand detection (Visa, Mastercard, Amex, Discover, JCB, UnionPay).
8. 🏦 **International Bank Account Number (IBAN) Engine**: ISO 13616 Modulo-97 checksum validator and issuing country code parser.
9. 🪙 **Multi-Chain Cryptocurrency Address & Cluster Tracing**: Format validation and direct blockchain explorer cluster routing for Bitcoin (BTC), Ethereum/EVM (ETH), Solana (SOL), and TRON (TRX).

### 🌐 3. Digital Network & Infrastructure Intelligence (DNINT)
10. 🌐 **IPv4 Subnet / CIDR Range Calculator**: Network ID, Broadcast IP, Netmask, Wildcard Mask, Usable Hosts Range, and Total Hosts counter.
11. 🏷️ **MAC Address & OUI Vendor Analyzer**: 48-bit MAC parser, OUI vendor prefix extractor, Unicast/Multicast frame check, and Globally/Locally Administered bit analyzer.
12. ✉️ **Universal Corporate Email Permutator**: Generates 36 standard corporate syntax patterns with instant Epieos, Hunter.io, and DeHashed verification links.

### 🔎 4. Advanced Search & Threat Dorking Studio
13. 🔎 **Multi-Engine Search & Threat Dork Studio**: Pre-configured dork templates for Exposed Passwords/Resumes, Leaked Office Docs, Database Backups (`.sql`), and Environment files (`.env`).
14. ☁️ **Multi-Cloud S3 Bucket & Blob Storage Enumerator**: Automated URL pattern generator for AWS S3, Google Cloud Storage, Azure Blob, and DigitalOcean Spaces.
15. 📹 **Open RTSP Webcams & IoT Infrastructure Dork Matrix**: Search queries for open RTSP feeds, IP webcams, Hikvision, Dahua, and Axis camera portals.

### 🔑 5. Cryptography, Artifacts & Digital Forensics (DFIR)
16. 🔑 **Cryptographic Hash Analyzer & Windows NTLM Engine**: Client-side calculation of MD5, SHA-1, SHA-256, SHA-512, and Windows NTLM with CrackStation & VirusTotal routing.
17. 🧩 **Forensic Multi-Decoder (CyberChef Lite)**: Base64, Hexadecimal, Binary, URL Encode/Decode, HTML Entities, ROT13, and Morse code.
18. ⏱️ **Forensic Timestamp & Artifact Epoch Converter**: Bidirectional conversion between Unix Epoch (Seconds/Milliseconds), Windows FILETIME (64-bit), Chrome/WebKit Epoch, and Human UTC ISO dates.

### 📍 6. Geospatial & Imagery Intelligence (GEOINT / IMINT)
19. 📍 **Geolocation Triangulator & SunCalc Shadow Estimator**: Decimal Degrees (DD) <-> DMS converter and SunCalc solar azimuth/altitude calculator for calculating photo timestamps from shadows.
20. 🖼️ **Client-Side Image EXIF Metadata & GPS Extractor**: Drag-and-drop photo inspector to extract camera make, model, lens, exposure, and GPS coordinates entirely in local browser memory without uploading to any server.
21. 🔍 **Multi-Engine Reverse Image & Facial Recognition Hub**: One-click routing to PimEyes, FaceCheck.ID, Yandex Visual, Google Lens, TinEye, and Bing Visual.

### 👥 7. SOCMINT & Operational Security (OPSEC)
22. 👤 **Global Social Media & Developer Handle Matrix**: Direct profile search across 40+ major platforms (Twitter, GitHub, Reddit, TikTok, LinkedIn, Steam, Telegram, etc.).
23. 📞 **International Phone Number (E.164) & Carrier HLR Parser**: E.164 standardization, international dialing code parser, and deep links for Numverify, Sync.me, and Truecaller.
24. 👥 **Synthetic Persona & Identity Generator**: Realistic persona generator (Name, DOB, Synthetic SSN/Card for research, fake email, bio, user-agent) for OPSEC undercover research.
25. 🧅 **Dark Web Gateway, Onion Mirrors & OPSEC Checklist**: Tor2Web clearnet mirror generator and interactive 10-point OPSEC investigation checklist.
