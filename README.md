## 🚀 How to Host on GitHub Pages (Free, 1-Minute Setup)

You can host this entire software suite on GitHub Pages with zero build steps or server maintenance:

1. **Create a new GitHub Repository**:
   - Go to [GitHub](https://github.com/new) and name your repository (e.g., `osint-apex` or `osint-workbench`).
   - Choose **Public** (or **Private** if you have GitHub Pro).
2. **Upload the Files**:
   - Upload the following files into the root of your repository:
     - `index.html` (The all-in-one workbench application)
     - `manifest.json` (PWA Web App Manifest)
     - `sw.js` (Service Worker for offline caching)
     - `.nojekyll` (Ensures GitHub Pages does not ignore underscore files)
     - `README.md`
3. **Enable GitHub Pages**:
   - In your repository, click **Settings** > **Pages** (under Code and automation).
   - Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
   - Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
4. **Access Your Live Software**:
   - Within 30 seconds, your site is live at:  
     `https://<your-username>.github.io/<your-repo-name>/`

## 📱 Mobile App Installation (PWA)

This workbench is a Progressive Web App (PWA) that installs as a standalone native app on any mobile device:

### 🍏 iOS (iPhone & iPad)
1. Open your hosted GitHub Pages URL (or local server) in **Safari**.
2. Tap the **Share** button (box with an arrow pointing up) at the bottom.
3. Scroll down and tap **"Add to Home Screen"**.
4. The OSINT Apex icon will appear on your home screen and open in full-screen standalone mode with offline caching enabled!

### 🤖 Android (Samsung, Pixel, Xiaomi, etc.)
1. Open the URL in **Chrome**, **Brave**, or **Firefox**.
2. Tap the three dots (⋮) in the top-right corner.
3. Tap **"Install App"** (or **"Add to Home Screen"**).
4. Launch directly from your app drawer.

## 💻 Running Locally (Offline / Air-Gapped)

You can run this application entirely offline on your computer without internet access:

### Option 1: Direct File Opening
Double-click `index.html` or `osint_apex_workbench.html` to open directly in Chrome, Firefox, Edge, or Safari.

### Option 2: Local HTTP Server
Run with Python (pre-installed on macOS/Linux/Windows):
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.
